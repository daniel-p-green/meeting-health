# Synthetic Fixtures

These files are fake examples for documentation and validation only.

They must not contain real Apple Health exports, calendar exports, email addresses, meeting links, names, locations, screenshots, or exact logs.

The fixture shape is intentionally simple:

- `synthetic_calendar_events.csv` shows meeting-like calendar rows.
- `synthetic_heart_rate.csv` shows timestamped heart-rate samples.

Real analysis should use live connector data inside Codex, not committed exports.
